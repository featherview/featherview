# Featherview — Own Look Implementation Plan

> **Own look** in `docs/roadmap.md` (decided: the maintainer accepted the mockups' recommendations).
> Builds on milestone 2–4 views (`ViewerView`, `ImageCanvas`, `StatusBar`, `ViewerToolbar`,
> `SettingsView`, `Batch*.swift`). Languages (milestone 6, plan
> `docs/superpowers/plans/2026-10-18-milestone-6-languages.md`, written in parallel) are not part of
> this plan, but every new user-facing string here goes through a SwiftUI string literal or
> `String(localized:)` so the catalog picks it up.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo, run it wave by wave with the `plan-wave` workflow. Steps marked **(screen)** need the Mac's screen: plan-wave agents skip them and report; the main session does them.

**Goal:** Featherview gets the look the spec now describes: the canvas under the glass toolbar with a
floating glass status strip, Graphite as the default background, optional auto-hiding bars, the
grouped-card form in Preferences and the batch steps, the feather in the empty window, short motion
with Reduce Motion respected, and a designed, translated disk image.

**Architecture:** The only new logic goes into `FeatherviewCore` and is unit-tested: `CanvasInsets`
(how far fit keeps the image from the window edges), `BarsAutoHide` (a pure state machine fed with
pointer, key and timer events), `BackgroundPreset` (the named background colours) and the disk-image
art renderer. The app wires them up: the canvas fills the window and `NSScrollView.contentInsets`
gives fit its clear area while zoomed content scrolls under the bars; the status strip becomes an
overlay with `panelBackground` (glass on macOS 26, material before).

**Tech Stack:** Swift 6, SwiftUI + AppKit (`NSScrollView` content insets, titlebar container alpha,
`NSAnimationContext`), Core Graphics + Core Text (disk-image art), `hdiutil`, Finder AppleScript,
Swift Testing.

**Spec:** `docs/spec.md` — "Viewer" (incl. "Default viewer"), "Toolbar", "Look", "Batch window › Window", "Preferences",
"Distribution".

## Global Constraints

- Minimum macOS 14.0; Liquid Glass only behind `if #available(macOS 26, *)`, the system material on 14/15 in the same shapes (reuse `View.panelBackground(cornerRadius:)` in `ViewerView.swift`).
- Default background `#1c1c20` (Graphite); presets Graphite `#1c1c20`, Black `#000000`, Grey `#808080`, White `#ffffff`, plus a custom colour.
- Auto-hide: off by default; rest 2 s; fade 200 ms; browsing keys (← → Space ⌫ Page Up/Down Home End) keep the bars hidden, any other key, pointer movement or the window's top edge show them.
- Motion: browsing instant; zoom step 120 ms; info panel 180 ms; bars fade 200 ms; Reduce Motion (`NSWorkspace.shared.accessibilityDisplayShouldReduceMotion`) → no animation.
- Colour: system accent for every control including Start; feather colours `#ffc766` → `#ff7a59` only in About, the empty-window hint and the disk image.
- Type: system font; `.monospacedDigit()` where numbers change in place.
- Budgets (`AGENTS.md`): prefetched next/previous ≈ 20 ms (`Navigate` p50 19 ms today); a task that changes the first window measures launch after a real ⌘Q (today ~377 ms median, runs 2–6).
- Layout uses leading/trailing, never left/right; user-facing text translatable; no copied icons, art or UI text from other apps; no cat imagery.
- Commits: conventional commits, no AI attribution lines.

## Review Focus

1. **Fit next to the bars:** resizing the window, hiding the status bar (View menu) or the toolbar must never leave a fit image under a bar or jumping when the bars auto-hide — `CanvasInsets` tests in Task 3 (`insetsDontChangeWhenBarsAutoHide`, `hiddenStatusBarFreesTheBottom`).
2. **Panels and menus:** the bars must not fade while the folder chooser, the F7/F8 panel, the info panel, a context menu or a sheet is open, or while the pointer is over a bar — Task 1 `noHidingWhilePanelOpen`, `noHidingOverBars`.
3. **Existing settings:** someone who picked black (or any colour) keeps it after the update; only the registered default changes — Task 1 `storedBackgroundSurvivesNewDefault`.
4. **Full screen:** the auto-hide machine stays out of full screen (the system's own on-hover toolbar handles it) — Task 1 `fullScreenNeverHides`.
5. **Disk image builds twice:** running `scripts/dmg.sh` again replaces its own previous output in `build/` without touching anything else, and a language without translations falls back to English text — Task 2 `missingTranslationFallsBackToEnglish` and the script's `rm -f` of exactly its output path.
