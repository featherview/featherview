Featherview viewer — build spec

All values in points (pt). Window shown at 1220 × 700 pt. Leading / trailing throughout; the layout mirrors for RTL, the picture never does.

macOS 26 Liquid Glass · macOS 14/15 system material fallback

1 · The picture is the only solid thing

Every control floats on glass and is translucent; the picture is opaque and the only element with a real shadow. Chrome never competes with it.

2 · One glass recipe, three shapes

Capsule (toolbar groups, status strip), 16 pt card (panels, sheets), 18 pt card (empty hint). Same fill, highlight and hairline everywhere.

3 · Numbers are quiet and aligned

Everything numeric is secondary colour with tabular figures (SF Pro monospaced digits) so the strip and panels never jitter while browsing.

Elevation

One key light from above, two layers per level: a tight contact shadow that anchors the edge and a wide ambient shadow that lifts the shape. Offset and blur grow by about 1.6× per level (y : blur ≈ 1 : 2.5); only the alpha changes between appearances. No element invents its own value.

Motion

PrincipleAnimation explains a state change, it never decorates. Nothing sits between a key press and the next picture. Hard ceiling 200 ms; the only exception is the About glow (300 ms fade with the window). Curves: ease-out for things that arrive, ease-in-out for things that move, linear for pure opacity.
Browsing0 ms. The next picture replaces the previous one with no crossfade; title and strip update in the same frame. Strip text fades 120 ms only when a different file arrives, never on zoom.
Zoom120 ms, ease-out, anchored at the cursor (centre from the keyboard), Fit included. Trackpad pinch: no easing at all, the fingers are the animation. E3 shadow and hairline switch off at the first frame beyond fit.
Rotation160 ms, ease-in-out, about the picture centre, so a 90° turn reads as the same picture. Repeated presses chain without waiting.
Info panel180 ms, ease-in-out: slides 24 pt from the trailing edge while fading 0 → 1; picture and strip refit on the same curve, in one movement. The toolbar toggle itself does not animate.
SheetsFolder chooser and F7: 160 ms, scale 0.97 → 1 with fade; close 120 ms reverse. No overshoot.
Move / TrashWith "show the next image" on: the leaving picture fades out 60 ms, the next one appears hard. Undo reverses it. Reads as "gone", not "replaced".
Bars at restAfter 2 s without input while browsing, toolbar groups and strip fade to 0 in 200 ms, opacity only, no travel (traffic lights and title stay). Mouse move or key: back in 120 ms. Panels and sheets never fade.
Hover / press80 ms fill change; on macOS 26 the glass press response. Toggled-on and disabled states switch without animation.
LoadingNo indicator before 150 ms. After that a system spinner centred in the fit area, or the previous picture dimmed to 0.5; it disappears hard when the picture lands.
Drop targetA 2 pt accent outline around the fit area fades in 120 ms while a folder or image is dragged over the window; out in 120 ms. Opacity only.
NeverCrossfades or slides between pictures; Ken Burns, parallax, bounce at the edges beyond the system rubber band; springs on panels or sheets; eased pinch zoom; animated toolbar glyphs; morphing title text; any feather flourish beyond the About fade.
Reduce MotionZoom, rotation, panel and sheet durations become 0 and things appear in place. Pure opacity changes (bars, strip fade, drop outline, About glow) stay, as they are not motion.

RTLBack/forward group, title and the trailing group swap sides; glyph order inside the trailing group reverses; chevrons flip (chevron.forward is direction-aware). Info panel opens from the leading edge. Status strip text is trailing-aligned. The picture itself is never mirrored.
Window inactiveGlyphs drop to the secondary token; glass keeps its fill.
Full screenSame chrome, same insets; bars fade as above. Background colour fills the screen.
Custom backgroundLuminance < 0.5 → dark tokens, else light. Glass fills are tinted by the material, so no per-colour tuning.
